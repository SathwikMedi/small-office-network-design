# Setting Up a Small Office Network

This project contains a Cisco Packet Tracer simulation file that demonstrates the setup of a basic yet functional network topology for a small office environment.

## 📁 File Included
- `Setting up a small office.pkt` – Cisco Packet Tracer file with full network configuration.

## 🛠️ Features Implemented
- VLAN configuration for department-level segmentation
- Static routing between VLANs or subnets
- DHCP server setup for dynamic IP allocation
- DNS and Web server simulation
- Proper device labeling and IP addressing
- Connectivity testing using PCs and servers

## 🧰 Tools & Technologies
- **Cisco Packet Tracer**
- **Networking Concepts:** TCP/IP, VLANs, Subnetting, Static Routing, DHCP, DNS

## 🎯 Purpose
To simulate a realistic network design that supports multiple departments in a small office. This setup improves security and manageability while allowing internet and inter-departmental communication.

## 🔧 How to Use
1. Open the `.pkt` file in Cisco Packet Tracer.
2. Observe the network topology and inspect device configurations.
3. Run simulations (e.g., ping, DNS, web access) to test connectivity and service availability.

## 📚 Learning Outcomes
- Understanding of basic enterprise network architecture.
- Hands-on experience with network services like DHCP and DNS.
- VLAN setup and inter-VLAN communication through routing.
